# SmallTV NM 3.13.0 — NM-TV-154

2026-11-21

产品显示名称统一为 **SmallTV NM**，固件标识为 `smalltv-nm`，版本为 `3.13.0`。升级保留设备已设置的主机名、WiFi、数据源、轮播、主题和图片。仓库地址、MQTT 集成标识和 GitHub OTA 历史资产名保留兼容性。

## 新增检索

- 城市：Weather／Display／Plane Radar 使用统一输入检索；常用城市、最近八个已选城市支持离线选择，更多城市通过 Open-Meteo 查询。必须主动选择，结果不自动应用。
- 时区：本地过滤中文与英文城市／国家、IANA 时区；仅使用设备支持的 POSIX／夏令时规则，保留原有自定义映射。暂不支持的城市时区明确提示。
- 股票／ETF：中文别名、常用代码及市场／来源标签，自动填入对应来源的草稿行；ESP32 可经设备检索 Yahoo 更多标的，短代码原样查询。Naver 使用离线常用条目或手工代码。
- 加密货币：常用别名与 Binance 活跃现货目录，精简目录在浏览器缓存最多 24 小时。联网失败保留预设及手工输入，预设不冒充已经验证的活跃市场。
- 输入支持约 350 ms 防抖、中文输入法、请求超时、过期响应丢弃；区分加载、无结果、联网失败。所有选择需明确保存。

## 安装与资源

已经使用本项目当前分区布局的设备：System → 上传对应 OTA。已开启 WireGuard 的 NM-TV-154 使用 `smalltv-nm-tv-154-wg-ota.bin`。`factory.bin` 是全新安装／旧分区迁移镜像，不能当作保留配置的普通 OTA。

本次新增查询入口随完整应用 OTA 一起更新。全彩 v2 图片库内容保持一致，当前已安装 v2 库的设备无需重复上传。首次安装可用 factory 镜像，或使用发布包内图片更新工具；不要覆盖自己的同名自定义资源。

手册位于 `manuals/`，中文、英文 PDF 各 17 页，第 2 版。`release.json` 给出软件身份、容量和网页摘要；`SHA256SUMS.txt` 可验证发布文件。网页的 `webui.html` 已包含检索脚本，不需要设备另装 JavaScript 文件。

## 实现与验证

固定 Yahoo 查询主机、沿用网页鉴权、查询最长 80 字节、结果最多八条、响应读取最多 16 KiB，设置 TCP／TLS／读取期限。ESP8266 保留离线列表及手工配置。公开服务是否可用取决于网络、地区、限流和供应商策略；查询成功不等于行情请求成功。

为满足现有 OTA 容量要求，生成网页使用锁定版本的 Terser 和 gzip；天气字形采用无损压缩。105 个字形解码输出与原始栅格逐字节一致，分区布局和显示功能保持一致。测试、构建与设备验证详情见同包复盘记录。
