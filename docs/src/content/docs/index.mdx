The GeekMagic SmallTV is a small cube with a 1.54" colour screen, an ESP inside, and a USB-C port. This firmware provides apps selected under General in its local web UI, plus Carousel and daily Timer scheduling. Supported builds offer weather clocks, stock/crypto charts, a local picture album, theme clocks and optional data integrations. Features vary by board. Read the [English user manual](/NM-SmallTV-Pro/manual/user-manual-en/) or [中文使用手册](/NM-SmallTV-Pro/manual/user-manual-zh/) for setup, everyday use and recovery.

![The SmallTV running its three modes](/NM-SmallTV-Pro/assets/screen.svg)

## Market data and optional integrations

<CardGrid>
  <Card title="Stock and crypto ticker" icon="seti:default">
    Price, change, percent change, and a sparkline for up to 8 rotating symbols. Data from Yahoo Finance with no backend, or your own webhook.
  </Card>
  <Card title="Claude usage meter" icon="seti:crystal">
    An animated mascot plus your 5-hour and 7-day usage bars with reset countdowns, fed over WiFi by the clawdmeter-daemon on your PC. The daemon can auto-discover several SmallTVs on the LAN and push usage to all of them at once.
  </Card>
  <Card title="Plane radar" icon="rocket">
    A scope centred on your location with nearby aircraft, headings, speed vectors, and callsigns, from the free adsb.lol or adsb.fi feeds or a LAN webhook.
  </Card>
</CardGrid>

Plus one thing that is not a mode: on every ESP32 board the firmware carries a [WireGuard client](/NM-SmallTV-Pro/features/wireguard/), so you can reach the device from outside your network without opening a port to the internet. The ESP32-C2 and the 8 MB SmallTV Pro have it in their only image; on the NM-TV-154, whose image is the tightest fit of the three, it comes in a second image you pick at install time.

## Pictures, clocks and temporary screens

NM-TV-154 includes four weather-clock layouts and a ten-package full-color picture library. Weather layout rotation, stock-symbol rotation and picture rotation are independent of General's app Carousel. See the complete manuals for the difference between selecting a tab, saving settings and showing an app.

A [Home Assistant screen](/NM-SmallTV-Pro/features/ha/) arrives over MQTT as a JSON draw list and the device shows it as a full 240×240 screen. A [notification](/NM-SmallTV-Pro/features/notify/) takes the panel for a few seconds when a script pushes one over HTTP, then puts back whatever was showing. And a [theme clock](/NM-SmallTV-Pro/features/themes/) replaces the screen with a clock face of your own: background art, animated sprites, clock and date text, and live values from JSON sources, installed as a `.stheme` package with no firmware rebuild.

![A Home Assistant screen pushed over MQTT, a notification overlay, and the Pixel Room theme clock](/NM-SmallTV-Pro/assets/screen2.svg)

## Design a clock face in SmallTV Studio

[SmallTV Studio](https://giovi321.github.io/smalltv-studio/) is the visual editor for theme clocks. It runs in the browser with nothing to install. Stack layers on a 240×240 canvas, preview the clock at any simulated time, bind fields to JSON data, then export a `.stheme` package or send it to the device over WiFi.

[![SmallTV Studio editing the Pixel Room theme](/NM-SmallTV-Pro/assets/studio.png)](https://giovi321.github.io/smalltv-studio/)

## Related projects

[SmallTV Pomodoro](https://github.com/davicorrea0/smalltv-pomodoro) is a separate alternative firmware for the SmallTV-ultra (ESP8266), built around a Pomodoro timer with a pixel-art tomato, clock faces, weather, and a photo album. A device runs either it or smalltv-mod. The two projects are working on a shared theme format, so that a clock face designed in SmallTV Studio runs on both ([#31](https://github.com/RockBase-lab/NM-SmallTV-Pro/issues/31)).
