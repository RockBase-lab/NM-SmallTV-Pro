---
title: Quick start
description: Five steps from power-on to a working screen.
---

For complete instructions, use the [English user manual](/NM-SmallTV-Pro/manual/user-manual-en/) or [中文使用手册](/NM-SmallTV-Pro/manual/user-manual-zh/).

1. Power the device from a stable 5 V USB supply.
2. If it cannot join a saved 2.4 GHz network, join the setup hotspot shown on screen. NM-TV-154's factory hotspot password is `12345678`; other variants normally use an open hotspot. Open `http://192.168.4.1`.
3. In **WiFi**, scan, choose your network, enter its password and press **Save & connect**. Rejoin your home network and open the device's displayed IP address.
4. In **Weather**, select your city; verify the timezone in **Display** and save.
5. In **General**, select Weather, Stock 1 or Pictures and save. Configure each optional integration before adding it to Carousel.

NM-TV-154's factory default is Detailed weather for Chengdu, China, using Asia/Shanghai (UTC+8). Saved locations, timezones and display modes survive firmware updates and reboot. Selecting a tab edits that feature; **General** controls the app that is shown. See the complete manual for hardware differences and recovery.
