title: First-time setup
description: Connect WiFi, choose your location and show the first app.
---

Follow [Quick start](/NM-SmallTV-Pro/manual/quick-start/) or the complete [English manual](/NM-SmallTV-Pro/manual/user-manual-en/) / [中文手册](/NM-SmallTV-Pro/manual/user-manual-zh/).

If a saved network cannot be joined, the device starts the setup hotspot shown on its screen. NM-TV-154's factory setup password is `12345678`; other variants normally use an open hotspot. Join it and open `http://192.168.4.1`. Save a 2.4 GHz home network in WiFi, wait for reboot, return to your home network and open the device's new displayed IP.

NM-TV-154 defaults to Chengdu, China and Asia/Shanghai (UTC+8). Choose your actual city in Weather and check the timezone in Display, then save. Choose the displayed app under General and save. Start with one working app before enabling Carousel, Timer or integrations. Browser tabs configure features; selecting a tab does not itself display that app.

Existing saved modes and explicit Carousel selections survive firmware upgrades. NM-TV-154's factory default is Detailed weather; Stock 1 contains Samsung Electronics, NVIDIA and Apple. Usage requires a computer daemon, Radar a valid center and feed, and HA a broker plus published screen definitions.
